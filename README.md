# MiniAI

MiniAI is a local agent that chats with a model on Lemonade Server and can use
tools for files, memory, knowledge search, web research, a dedicated browser,
desktop UI automation, and sandboxed coding — always with explicit permission
prompts for risky actions. Start with [USER_GUIDE.md](USER_GUIDE.md) for
everyday use; [ARCHITECTURE.md](ARCHITECTURE.md) describes stages, security
choices, and known limitations.
